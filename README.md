# 💕 Surprise Card

A personalised surprise card web app — filled with messages, photos, videos, countdowns, and memories — made just for someone special.

## 🚀 Deploy to Netlify

1. Push this folder to a GitHub repo.
2. Go to [Netlify](https://app.netlify.com/), click **Add new site → Import an existing project**.
3. Connect your GitHub repo.
4. Set **Build command** = *(leave empty)* and **Publish directory** = `.`
5. Click **Deploy**. Done!

## 🔧 Configuration

- **Supabase URL & anon key** → `js/config.js`
- **Public card link** → `js/config.js` (`window.PUBLIC_CARD_LINK`)
- **Fallback admin password** → `js/config.js` (`window.FALLBACK_ADMIN_PW`)
